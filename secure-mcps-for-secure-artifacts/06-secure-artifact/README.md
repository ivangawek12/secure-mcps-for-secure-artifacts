# 06 — Secure Artifact

## Design pattern

Separate capabilities by purpose.

```text
News MCP
  |
  +-- get_news()

Private Data MCP
  |
  +-- search_documents()

Communication MCP
  |
  +-- send_email()
```

Do not expose everything through one giant server when the artifact does not need everything.

## Additional controls

For sensitive actions:

- use human approval;
- keep read and write capabilities separate;
- log high-impact actions;
- review connected MCPs periodically;
- remove unused connectors;
- validate authentication and authorization;
- treat external content as untrusted.

## Key principle

The artifact is generated by AI.

Its permissions should still be intentionally designed.
